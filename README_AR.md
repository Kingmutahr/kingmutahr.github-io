# الموقع التعريفي — المهندس أبو عدي مطهر السفياني

هذه نسخة أولية جاهزة للنشر كموقع شخصي تعريفي باستخدام GitHub Pages.

## قبل النشر
1. أنشئ حساباً في https://github.com إذا لم يكن لديك حساب.
2. أنشئ مستودعاً عاماً جديداً بالاسم الدقيق: `USERNAME.github.io` مع استبدال USERNAME باسم حسابك.
3. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
4. افتح Settings ثم Pages، واختر النشر من الفرع `main` والمجلد `/ (root)` ثم Save.
5. بعد ظهور رابط الموقع، افتحه وتأكد من عمله عبر HTTPS.

## خطوة مهمة جداً: استبدال الرابط التجريبي
في الملفات `index.html` و`robots.txt` و`sitemap.xml` استبدل كل ظهور للنص:
`YOUR-USERNAME`
باسم حساب GitHub الفعلي، ثم ارفع الملفات المعدلة.

## الفهرسة
- أضف رابط الموقع إلى Google Search Console وتحقق من الملكية.
- أرسل `https://USERNAME.github.io/sitemap.xml`.
- استخدم فحص URL ثم اطلب الفهرسة للصفحة الرئيسية.
- أضف الموقع إلى Bing Webmaster Tools وأرسل خريطة الموقع.
- لا توجد ضمانة لوقت الفهرسة أو ظهور الموقع في كل إجابة ذكاء اصطناعي.

## تحديث المحتوى
راجع الاسم والوصف والخدمات والروابط قبل النشر. أضف فقط صورك الحقيقية وأعمالك التي توافق على نشرها. لا تضف أرقام هاتف أو عنواناً شخصياً إلا إذا رغبت في نشرهما علناً.

## ملاحظة
GitHub Pages مناسب لهذا الموقع التعريفي الثابت. لا تستخدمه لتخزين بيانات العملاء أو كلمات المرور أو تشغيل نظام بيع/دفع.
